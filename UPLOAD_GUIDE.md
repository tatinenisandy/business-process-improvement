# Upload guide

Upload these six files to the root of `business-process-improvement`:

-   README.md
-   process_mapping.md
-   requirements_document.md
-   stakeholder_matrix.xlsx
-   implementation_plan.xlsx
-   uat_test_cases.xlsx

On GitHub: open the repository → **Add file** → **Upload files** →
select the six files → **Commit changes**.

The case study is illustrative and uses synthetic data. Review it and
replace assumptions only with details you can substantiate.
